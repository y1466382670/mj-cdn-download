# mj-cdn-download

**English** | [中文](README.zh-CN.md)

A self-hosted service that downloads Midjourney images into your own storage and returns a URL you control.

## Background

Images generated by Midjourney are hosted on `cdn.midjourney.com`. To keep those results, serve them from your own domain, or pass them to another system, you first need to fetch the file and store it somewhere you operate.

Fetching that host directly is unreliable. Some networks are blocked, and the original address is a poor permanent link for an application. This service turns that step into an HTTP API you deploy yourself. A caller submits an image URL. The service downloads the file and stores it on this machine, on your CDN, or in your object storage.

It is meant for teams that want to own how these images are stored and delivered. To generate images by calling Midjourney, use [TTAPI](https://ttapi.io).

## Deploy

```bash
git clone https://github.com/y1466382670/mj-cdn-download.git
cd mj-cdn-download
docker compose up -d --build
```

Build it locally:

```bash
go build -o mj-cdn-download .
./mj-cdn-download
```

The service listens on `:8080`. With no external storage configured, files are written to `./data` and served by this process. Open `http://127.0.0.1:8080` for a short example. The page is in English, with a switch to Chinese.

Other runtime settings are listed in [.env.example](.env.example).

## API

`POST /download` with a JSON body.

```json
{
  "url": "https://cdn.midjourney.com/xxxx/0_0.png",
  "proxy": "http://user:pass@host:port"
}
```

`url` is the Midjourney image address. `proxy` is optional. When it is set, the service uses that proxy to reach the image. When it is omitted, the service connects directly.

```bash
curl -s http://127.0.0.1:8080/download \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://cdn.midjourney.com/xxxx/0_0.png","proxy":"http://user:pass@host:port"}'
```

A successful call has `"code": 200`:

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "url": "http://127.0.0.1:8080/files/midjourney/20261021/ab12.png",
    "key": "midjourney/20261021/ab12.png",
    "size": 123456,
    "source_url": "https://cdn.midjourney.com/xxxx/0_0.png"
  }
}
```

| Field | Meaning |
| --- | --- |
| `url` | Address of the stored image. After you configure a CDN or object storage, this is your own address |
| `key` | Storage key, the same path used for the object |
| `size` | File size in bytes |
| `source_url` | Image address from the request |

On failure the HTTP status is still 200. Use `code` in the body. `200` is the only success value.

## Storage

By default the file stays on this service. `url` is `http://<host>/files/` joined with `key`.

Your CDN and object storage can be configured separately or together. When both are set, the file is uploaded to object storage and `url` uses your CDN hostname.

### Your own CDN

The file remains in `DATA_DIR` on this service. Point your hostname at `/files/` on this service, then set the prefix used in the response:

```bash
CDN_BASE_URL=https://img.example.com/files
```

`url` becomes `https://img.example.com/files/midjourney/20261021/ab12.png`. Do not include a trailing slash. If the hostname root maps directly onto the storage key, use `https://img.example.com`.

### Cloudflare R2

Create a bucket in Cloudflare R2 and an API token that can read and write objects. The R2 overview shows the Account ID. The S3 endpoint is `https://<Account ID>.r2.cloudflarestorage.com`.

That S3 endpoint is for uploads. It is not a public image URL. Attach a public hostname to the bucket (a custom domain or `r2.dev`) and put that hostname in `CDN_BASE_URL`.

```bash
STORAGE=s3
S3_ENDPOINT=https://<account_id>.r2.cloudflarestorage.com
S3_REGION=auto
S3_BUCKET=your-bucket
S3_ACCESS_KEY=your-access-key
S3_SECRET_KEY=your-secret-key
S3_PATH_STYLE=true
CDN_BASE_URL=https://img.example.com
```

`S3_ENDPOINT`, `S3_BUCKET`, `S3_ACCESS_KEY`, and `S3_SECRET_KEY` are all required. When the endpoint contains `r2.cloudflarestorage.com`, `S3_PATH_STYLE` may be omitted and is treated as `true`.

`CDN_BASE_URL` is the bucket root. Do not add a trailing slash, and do not append `/files`. A successful response then has `url` `https://img.example.com/midjourney/20261021/ab12.png`.

With Docker Compose, change `STORAGE` from `local` to `s3` and set the variables above. While `STORAGE=local`, any `S3_*` values are ignored.

### Other object storage

Alibaba Cloud OSS and any other S3-compatible store use the same `S3_*` variables. Replace the endpoint, region, and bucket with the provider's values. For virtual-hosted addresses, set `S3_PATH_STYLE=false`. Set `CDN_BASE_URL` when the public URL should use your own hostname.
